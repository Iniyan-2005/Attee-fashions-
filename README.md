# Attee-fashions-

A luxury boutique clothing store website for **Attee Fashions — Chennai**, built with Next.js (App Router), Tailwind CSS v3, and GSAP animations.

## Features
- **Hero Section**: Editorial typography, arched lookbook imagery, rotating circular badge, and floating apparel card.
- **GSAP Animations**: Fluid entrance timelines, ScrollTrigger reveals, micro-interactions, and smooth card transitions.
- **Catalogue & Collections**: Interactive category filtering (Men's, Women's, Kids, Casual, Formal) with dynamic stock counts.
- **WhatsApp Commerce Engine**: Instant enquiry pre-filled with product title and pricing.
- **Physical Store & Google Maps**: Embedded interactive map pointing to 12/5b, Mugalivakkam Main Rd, Madanandapuram, Chennai.
- **Responsive Design**: Pixel-perfect layout for mobile, tablet, and desktop with custom SVG favicon and mobile drawer.

## Tech Stack
- **Framework**: Next.js (App Router, TypeScript)
- **Styling**: Tailwind CSS v3
- **Animations**: GSAP + ScrollTrigger + @gsap/react
- **Icons**: Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
